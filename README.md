# InvoicePro — Invoice & Receipt Generator

InvoicePro is a responsive web application that helps small businesses create invoices, calculate payments, track outstanding balances, and print payment receipts.

[Open InvoicePro](https://dagne-64-studio.github.io/InvoicePro/)
**Try InvoicePro online:** https://dagne-64-studio.github.io/InvoicePro/

**Source Code:** https://github.com/dagne-64-studio/InvoicePro

InvoicePro helps small businesses create invoices, track payments, calculate outstanding balances, and print receipts.
## Features

- Create and manage invoices
- Calculate invoice totals and outstanding balances
- Track paid, unpaid, and partially paid invoices
- Save, search, edit, and delete invoices
- Print invoices and payment receipts or save them as PDF
- Upload a business logo
- Responsive design for desktop and mobile devices

## Technologies

- HTML5
- CSS3
- JavaScript
- Git and GitHub Pages

## Project Purpose

Built as a practical business tool for freelancers, entrepreneurs, and small businesses.
