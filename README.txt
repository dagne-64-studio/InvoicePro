# InvoicePro

InvoicePro is a web-based invoice and receipt generator.

## Features

- Create and calculate invoices
- Add invoice items, quantities, and prices
- Calculate payments and outstanding balances
- Save, search, edit, and delete invoices
- Generate payment receipts
- Print invoices and receipts or save them as PDF
- Upload a business logo
- Filter invoices by payment status
- Responsive mobile layout

## Technologies

- HTML
- CSS
- JavaScript

## How to Run

1. Open `index.html` in a web browser, or use the VS Code Live Server extension.
2. Create an invoice and test the available features.

## Project Files

- `index.html` — application structure
- `style.css` — styling and responsive layout
- `script.js` — application functionality
